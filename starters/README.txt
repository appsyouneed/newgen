STARTER IMAGES
==============

Place up to 4 reference photos here for quick one-click loading in the Picgen tab.

File names must be exactly:
  start1.jpg
  start2.jpg
  start3.jpg
  start4.jpg

How it works:
- Each file corresponds to a "Start 1" through "Start 4" button in the Photo Editor tab
- Clicking a Start button instantly loads that image as input — no browsing or uploading needed
- Great for keeping your most-used subjects (yourself, a partner, a character) one click away

Rules:
- Must be .jpg format
- Any resolution works (automatically resized by the pipeline)
- You can use 1, 2, 3, or all 4 slots — missing files are simply ignored
- Replace any time — changes take effect on next app restart
